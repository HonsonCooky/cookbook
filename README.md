# cookbook

My personal site: an extension of my CV, with a little more about who I am, where I've worked, and what I get up to
outside of it.

Live at [honsoncooky.github.io/cookbook](https://honsoncooky.github.io/cookbook/).

## What's in here

- `index.html` - the site itself: about, experience, education and interests.
- `cv/` - where I build my CVs. I'm a developer, so for personal documents I'd rather write HTML and CSS than wrestle
  with Word. The page is a fixed A4 sheet; hit "Print / Save as PDF" and out comes the CV.
- `public/` - shared styles, fonts and images.

Plain static HTML, no build step. GitHub Pages serves `main` as is.
